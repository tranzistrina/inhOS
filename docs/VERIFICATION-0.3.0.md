# inhOS 0.3.0-alpha — отчёт USB

## Границы проверки

**Heltec Wireless Paper физически отсутствует. Windows и macOS недоступны.** Не проводились: прошивка реальной платы, открытие CP2102 в Windows/macOS, аппаратный DTR/RTS reset, отсоединение кабеля/питания на Flash-записи, осмотр E-Ink/кнопки, измерение RAM/тока на ESP32, фактический Deep-sleep после выхода. Нельзя считать успешную сборку подтверждением этих свойств.

## Автоматические проверки

`test/usb_test.py`: Python-клиент общается по двустороннему потоку с **настоящими Decoder/Server из lib/InhCore/src/UsbFs.h**, host-хранилище заменяет Arduino/LittleFS. Отдельный тест использует настоящий pyserial 3.5 и Linux pseudo-TTY. Вводятся ошибки кадра, повреждения ответов и потеря ACK, обрыв порта и сброс серверного процесса.

Покрытие:

- 8 приложений по 10 КиБ, 5 корректных GINH, книга ровно 3 МиБ; список всех 14 файлов; скачивание каждого и SHA-256 сравнение.
- CRC NACK/повтор, повторная передача запроса с потерянным ACK без двойной записи или сдвига скачивания; повреждённый ответ.
- Отмена upload/download, сохранение предыдущего файла и локального destination; полная CRC-ошибка; неверный UTF-8, повреждённая GINH.
- Перезагрузка во время upload: отказ старого session, временный файл удаляется при старте, старый пользовательский файл остаётся. Обрыв порта: старая версия остаётся; временный файл удаляется тайм-аутом 15 с.
- Удаление книги/индексов и всех файлов с обязательной фразой подтверждения; запрет NVS, прошивки, индексов, вложенных путей и NUL. Защищённые sentinel-файлы host-адаптера остаются неизменными. Это проверка политики, а не реальное чтение NVS контроллера.
- Выбор/сброс заставки, локальная PNG/JPG/WebP и FB2 конвертация.
- 80 повторных сеансов с upload/download под ASan/LSan в CI и ещё 80 в отдельном несаницированном процессе с upload/download/list/info: Python tracemalloc, RSS host-процесса, неизменность числа открытых дескрипторов. Протокольные буферы C++ фиксированного размера; данные идут по 512 байт. Предварительный локальный прогон: Python retained delta 316 байт, host RSS delta 52 КиБ (не ESP32 RAM, значения зависят от запуска).
- windows.py и macos.py как самостоятельные `--self-test` точки запуска, импорт протокола/конвертера/CLI. Это не тест native GUI этих ОС. Bash-launcher проверяется `bash -n`; BAT включён как готовый текст, Windows cmd.exe здесь не выполнялся.

Сохранены прежние core/VM/ридер/кнопка/сон/батарея, portal JS, converter и LittleFS host-тесты. В CI новый тест запускается после их успешного прохождения; прошивки собираются для apps_v12/reader_v12/apps_v11/reader_v11, пакет публикуется только после успеха всех jobs. Статус и логи конкретной сборки смотрите в GitHub Actions. SHA-256 поставляются рядом с бинарником/архивами.

Таблица partitions.csv не изменена. Обновление только firmware.bin на 0x10000; erase-all отключён. Native USB CDC остаётся выключенным, UART0 115200 используется CP2102. USB и Wi-Fi не обслуживаются одновременно: вход в USB останавливает сеть/VM/индексацию, главная петля обслуживает только UART/кнопку; выход закрывает временные файлы и возвращает обычное меню. Логи/пакеты синхронизированы mutex.

## Обязательная аппаратная приёмка

1. Обновить 0.2.1 с сохранёнными файлами записью только apps_v12 firmware.bin на 0x10000. Проверить файлы, ориентацию, выбранную заставку.
2. На Windows 10/11 и Intel/Apple Silicon Mac установить Python/Tk/CP210x, проверить запускатели/занятый порт/автопоиск/GUI. Открытие порта с DTR/RTS reset должно восстановить USB-режим.
3. Повторить весь набор 8×10 КиБ + 5 фото + книга 3 МиБ. Сверить SHA-256 выгруженных файлов. Проверить NoSpace при нехватке места под новую копию.
4. Отключать USB/питание на разных блоках и во время commit; повторно подключать. Старая или полностью новая версия должна быть целой, незавершённая копия не должна подменять файл. Сама LittleFS гарантирует атомарный rename, но электроника не испытана.
5. Проверить E-Ink статусы и выход 3 кликами/удержанием, отмену передачи, отсутствие Deep-sleep во время USB. После выхода проверить обычный сон/однократный финальный кадр/GPIO0 wake, батарею, TXT/FB2 и приложения, просмотр фото и Wi-Fi-портал.
6. На ESP32 замерить heap/minimum/largest и открытые файлы после многих USB-сеансов. Host RSS/tracemalloc не заменяют эти замеры. RSS измеряется отдельно от ASan: его quarantine намеренно удерживает уже освобождённые блоки; реальное отсутствие утечек дополнительно проверяет LSan при завершении процесса.
