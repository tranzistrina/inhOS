# inhOS 0.4.0 — проверка оглавления

**Аппаратных испытаний на Heltec не было. Native GUI Windows/macOS также не запускались.** Проверки ниже выполнялись на компьютере и в CI, а не на ESP32. Первоначальные USB и memory отчёты: VERIFICATION-0.3.0.md / VERIFICATION-0.2.0.md.

## Проверка присланной пользователем FB2

Исходник 1 553 101 байт, XML-декларация Windows-1251. Новый конвертер сохранил 89 пунктов оглавления с вложенностью. Контейнер 2 608 282 байта; начало текста 2046. Настоящие C++ функции Book.h и paginate из прошивки построили 5352 страницы при 40×8; **все 89 переходов** совпали с началом страницы выбранной главы. Повторное открытие конверта/проверка CRC прошли. Python и JavaScript конвертер портала (с DOM-деревом, построенным из исходной книги реальным XML-парсером) создали побайтово одинаковые данные.

Полный текст и конверт присланной книги не публикуются в репозитории или архиве прошивки. В публичных тестах используются собственные синтетические FB2, включая Windows-1251, вложенные разделы/части, inline-текст, стихи, отдельное body примечаний, пустое оглавление и 1024 главы.

## Автоматические тесты

- Реальный Button: один/два/три/четыре клика, отсутствие преждевременного Triple после третьего отпускания, hold/wake suppression из старых тестов.
- Реальный ContentsState: выбор следующей/предыдущей главы с wrap, точный возврат на исходную страницу, TXT без глав.
- Реальные C++ Book.h/ChapterCursor/pageForOffset/paginate: проверка структуры/CRC, каждый переход на начало главы, полный индекс без метаданных в видимых страницах, повторное открытие.
- Повреждения длины, таблицы/текста/CRC, неправильные/неупорядоченные смещения, длинные Unicode-заголовки, пределы числа пунктов; запрет DTD/ENTITY.
- Побайтовая совместимость Python и портального JS: UTF-8 позиции, CRC32, вложенность; кодировка из декларации/BOM. DOM браузера в host-тесте является контролируемым двойником: тест не заменяет запуск настоящего браузера.
- Сохранены core/VM/сон/батарея, USB fault-injection/pyserial pseudo-TTY/160 сеансов, LittleFS/8 приложений/5 фото/3-МиБ книга, конвертер изображений и портал. Новая FB2 также проверяется загрузкой/скачиванием по USB и отклонением повреждённой таблицы до замены.

Команды: `./tools/test.sh`, `node test/portal_test.cjs`, `python3 test/books_test.py`, `python3 test/usb_test.py`, прежние storage/converter тесты. CI использует ASan/UBSan для native C++ и собирает apps_v12/reader_v12/apps_v11/reader_v11. Фактический статус/логи — в соответствующем GitHub Actions run. Архивы публикуются только после успеха всех jobs.

## Ещё не проверено на устройстве

Различение четырёх реальных нажатий на GPIO0/дребезг конкретной кнопки; читаемость E-Ink списка и отступов/заряда в двух ориентациях; время и пик RAM индексации 2,6-МБ книги на ESP32; глава/отмена после настоящего Deep-sleep; реальная передача этой FB2 через CP2102/Wi-Fi и сохранение файлов при обновлении на 0x10000. Нужно выполнить на Heltec. Успешная сборка и host-навигация не являются подтверждением этих физических свойств.
