# Глаголъ 0.1

Небольшой интерпретируемый язык с Python-подобными отступами и лексикой, стилизованной под церковнославянскую. Это не исторически точный церковнославянский и не реализация CPython.

Файлы UTF-8 `.inh`, отступы по 4 пробела. Комментарии `#`. Числа double, строки, числовые массивы. Имена допускают кириллицу.

```
сумма = 0
для иже въ ряд(10):
    аще иже == 5:
        продолжи
    сумма += иже
инако_это_имя = 1
дондеже сумма < 100:
    сумма += 1
```

Слова: `аще`, `инако`, `дондеже`, `для`, `въ`, `прерви`, `продолжи`, `истина`, `ложь`, `и`, `или`, `не`. `инако:` следует за блоком `аще`. Операторы `+ - * / // % **`, сравнения, присваивание и `+= -= *= /=`. Логические операторы с коротким замыкканием. Индексы массива от нуля, присваивание `а[0] = 42`; отрицательные индексы не поддержаны.

Встроенные функции:

| Функция | Смысл |
|---|---|
| `ряд(конец)` / `ряд(начало, конец, шаг)` | Числовой массив для обхода, конец исключён |
| `массив(длина, значение=0)` | Массив в RAM |
| `длина(значение)` | Число элементов массива / байтов строки |
| `число`, `строка` | Преобразования |
| `синус`, `косинус`, `тангенс`, `пи()` | Углы в радианах |
| `корень`, `модуль`, `пол`, `округли`, `степень` | Математика |
| `очисти()` | Очистить кадровый буфер |
| `пиксель(x,y)` | Чёрный пиксель |
| `линия(x1,y1,x2,y2)` | Чёрная линия |
| `текст(x,y,строка)` | Текст; y — базовая линия |
| `яви()` | Отправить кадр на дисплей |
| `жди(мс)` | Приостановить приложение, сохранив обработку кнопки/сети |
| `кнопка()` | Забрать событие: 0 нет, 1 один, 2 двойной, 3 тройной клик |
| `время()` | Миллисекунды с запуска ESP32 |
| `вайфай(SSID,пароль)` | Аппаратная точка доступа, пароль 8..63 символа |
| `сайт(html)` | HTTP-сайт на `/`, порт 80 |
| `адрес()` | IP точки доступа |

Нет доступа приложений к flash, файлам, GPIO, нативному коду или памяти ОС. Данные приложения исчезают после выхода. Не реализованы функции пользователя, классы, импорты, файловый ввод-вывод и полный Python API.

Ограничения: исходник 32 КиБ, 1024 строки, 8192 инструкции, вложенность выражений 24, массив 1024 элемента, строка 2048 байт, суммарные данные строк/массивов 48 КиБ. Это лимит данных, не точный лимит всей кучи интерпретатора. Компиляция использует дополнительную память. Выполнение по одной инструкции за проход системного цикла. Удержание кнопки завершает и бесконечный цикл.
