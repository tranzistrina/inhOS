# Зависимости и происхождение

Новый прикладной код: `src/`, `lib/InhCore/`. Код и графика KniGO не скопированы. Известное поведение ридера задано пользователем; ранее выполнялся анализ его бинарного дампа, поэтому термин «чистая комната» к процессу неприменим.

- heltec-eink-modules: https://github.com/todd-herbert/heltec-eink-modules, commit 9207eb6ab2b96f66298e0488740218c17b006af7. Открытый драйвер дисплея и GFX. GPL-3.0 / включённые лицензии компонентов.
- U8g2_for_Adafruit_GFX 1.8.0: https://github.com/olikraus/U8g2_for_Adafruit_GFX. BSD / лицензии включённых шрифтов.
- Arduino ESP32 через PlatformIO espressif32 6.10.0: https://github.com/espressif/arduino-esp32. LGPL-2.1 и лицензии ESP-IDF/компонентов.

Изменение бренда не является гарантией отсутствия претензий правообладателей. Лицензии сторонних компонентов сохраняются. Репозиторий содержит собственный код и ссылки/точные версии зависимостей.
