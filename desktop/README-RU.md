# inhOS USB-файлы — Windows 10/11 и macOS

Требуется прошивка **inhOS 0.4.1-alpha apps_v12**. Основа USB — 0.3.0-alpha; 0.4.0 добавила точное оглавление FB2, 0.4.1 распознаёт заголовки в уже сохранённом обычном TXT. Обмен без Wi-Fi по встроенному CP2102 USB-UART, 115200 бод. Это готовые Python-программы, а не самостоятельные EXE/DMG: необходимы Python и зависимости. При первом запуске запускатели создают рядом `.venv` и устанавливают pyserial/Pillow из requirements.txt (потребуется Интернет). Для дальнейшей работы Интернет не нужен.

## Сначала один раз обновить прошивку

Записать **только apps_v12/firmware.bin по адресу 0x10000**, без erase-all. Не писать merged FIRST_INSTALL при обновлении. Таблица 8-МБ разделов не менялась, LittleFS и настройки остаются. Сначала сохраните резервную копию важных пользовательских файлов.

После обновления для загрузки/скачивания/удаления больше не нужны esptool, Wi-Fi или повторная перепрошивка.

## Подключение

1. Подключите Heltec кабелем USB **с передачей данных**.
2. На Heltec откройте «Настройки → USB-файлы»: один клик меняет пункт, два открывают.
3. Запустите программу, выберите порт и «Подключить». CP210x показываются первыми; произвольный порт можно ввести вручную. Дождитесь версии прошивки, свободного места и списка файлов.
4. Если открытие порта сбросит ESP32, USB-режим восстановится автоматически. Первое соединение может занять до 24 секунд. Если режима нет, сообщение предлагает включить его на устройстве.
5. «Отключить» закрывает передачу/порт и возвращает устройство в главное меню. На устройстве 3 клика или удержание также выходят. Не открывайте одновременно Serial Monitor, esptool, другой клиент или терминал на том же порту.

При обрыве соединения незавершённый временный файл удаляется по тайм-ауту 15 с либо при следующем подключении/сбросе. После 60 с без запросов установленное соединение закрывается, устройство возвращается в обычное меню и восстанавливает штатный таймер сна. До первого подключения USB-режим ожидает компьютера и **не спит**. GUI держит соединение PING-запросами. Процесс передачи не должен вызывать перезапуски экрана на каждом блоке: E-Ink меняется при входе/установлении/потере соединения, выходе и изменении процента батареи.

## Windows 10/11

- Установите Python **3.10+** с python.org, включая Tcl/Tk и Python Launcher `py`. Отдельно драйвер Silicon Labs CP210x VCP, если мост не определился автоматически.
- Распакуйте ZIP в обычную доступную для записи папку. Дважды откройте **inhOS-Windows.bat**. Не запускайте из самого ZIP.
- Выберите, например, COM3. Закройте занявший его Serial Monitor. При ошибке прав/занятого порта программа выдаёт сообщение, файл на устройстве не удаляет.
- Ручной запуск: `py -3 -m pip install -r requirements.txt`, затем `py -3 windows.py`.

## macOS — Apple Silicon и Intel

- Установите Python **3.10+** с python.org с Tcl/Tk. Universal2 Python подходит для обеих архитектур. Если используете Homebrew Python, нужен соответствующий пакет python-tk.
- Распакуйте ZIP. Откройте **inhOS-macOS.command**. При блокировке файла системой используйте правый клик → «Открыть» или Terminal: `bash /путь/к/inhOS-macOS.command`.
- Ожидаемый порт `/dev/cu.usbserial-*`; список содержит и другие CP210x/последовательные порты. Не выбирайте Bluetooth-порт. При необходимости установите CP210x VCP драйвер Silicon Labs.
- Ручной запуск: `python3 -m pip install -r requirements.txt`, затем `python3 macos.py`.

Разрешения/драйверы реальных Windows/macOS и GUI в этих ОС **не проверялись в данной среде**. Обе точки запуска проверены на Linux в режиме `--self-test`; настоящий pyserial дополнительно проверен через Linux pseudo-TTY. Это не доказательство совместимости с конкретным драйвером CP2102 на Mac/Windows.

## Оглавление FB2 на устройстве

В читалке четыре клика открывают список глав. Один клик — вниз, три — вверх, два — открыть главу. Четыре клика или удержание отменяют выбор и возвращают исходную страницу. Тройное нажатие распознаётся после паузы 360 мс, чтобы отличать его от четырёх. После выбора главы новая позиция сохраняется обычным ридером. В 0.4.1 уже сохранённую книгу TXT повторно загружать не требуется: заголовки распознаются на устройстве, страницы остаются прежними. Для произвольных названий глав без явных признаков можно загрузить исходную FB2, чтобы получить её точную структуру. Если заголовки не распознаны, текст всё равно доступен как обычно.

## Файлы и действия

- **Загрузить / фото…** — один или несколько INH/GINH/TXT/FB2/PNG/JPG/WebP. Приложения сохраняются как `.inh` (не более 32 КиБ). Картинки автоматически конвертируются Pillow в GINH 250×122, белые поля, порог 128, с учётом EXIF/прозрачности. FB2 преобразуется в UTF-8 текст с сохранённым оглавлением INHBOOK/1: названия/вложенность разделов и точные байтовые позиции, без картинок/разметки/сносочных связей. XML-кодировка (включая Windows-1251) определяется автоматически. Сохранённый book.txt содержит заголовок и таблицу оглавления перед текстом; читалка их не показывает. Для такого файла требуется прошивка 0.4.0+, клиент проверяет поддержку до начала загрузки. TXT должен быть UTF-8 без NUL; имя на устройстве всегда `/book.txt`, старая книга заменяется после проверки. INH — UTF-8 без NUL, синтаксис проверяется уже при запуске на устройстве.
- Для фото и приложений имена приводятся к ASCII: не-ASCII символы → `_`, основа до 30 символов. Совпавшие имена заменяют файл. Для сохранения разных файлов используйте разные имена; CLI позволяет `--name /other.inh`.
- **Скачать…** — выбранные файлы; проверка полного CRC32, безопасная локальная замена только после успеха. Множественный выбор скачивается в папку.
- **Удалить** — подтверждение выбранных файлов; книга удаляется вместе с индексами. **Очистить всё** — отдельное подтверждение, только пользовательские файлы/индексы. Прошивка, разделы и произвольные NVS-ключи недоступны. Позиция удалённой книги/выбор удалённой заставки сбрасываются; разворот сохраняется.
- **Выбранное фото для сна** — выделите одну GINH. Выбор сохраняется в NVS и работает после перезапуска. **Встроенная заставка** возвращает встроенную картинку.
- **Отменить передачу** — отменяет загрузку/скачивание на ближайшей границе подтверждённого блока. Во время окончательной атомарной фиксации отмена уже не гарантирует откат успешно сохранённого файла. Передача/хеширование не выполняются в потоке GUI.

Для безопасной замены на устройстве требуется свободное место **под весь новый файл + 8 КиБ**. Старый файл остаётся на месте до успешного rename. На существующем разделе нельзя одновременно разместить две книги по 3 МиБ: если старую большую книгу требуется заменить, сначала скачайте резервную копию и отдельно подтвердите её удаление. Программа не удаляет старую книгу автоматически ради освобождения места.

Поддержка 8 приложений по 10 КиБ, 5 фотографий и книги 3 МиБ проверена в тестовом файловом адаптере протокола. Реальный LittleFS дополнительно проверяется прежними host-тестами. Электрические отключения питания/кабеля на Heltec не проверены.

## CLI

В распакованной папке после установки зависимостей:

```sh
python inhfs_cli.py ports
python inhfs_cli.py --port COM3 info
python inhfs_cli.py --port COM3 list
python inhfs_cli.py --port COM3 upload demo.inh
python inhfs_cli.py --port COM3 upload photo.webp --name /sleep.ginh
python inhfs_cli.py --port COM3 upload novel.fb2
python inhfs_cli.py --port COM3 download /demo.inh backup.inh
python inhfs_cli.py --port COM3 delete /demo.inh
python inhfs_cli.py --port COM3 get-sleep-photo
python inhfs_cli.py --port COM3 set-sleep-photo /sleep.ginh
python inhfs_cli.py --port COM3 set-sleep-photo builtin
python inhfs_cli.py --port COM3 wipe --confirm
python inhfs_cli.py --port COM3 cancel
python inhfs_cli.py --port COM3 disconnect
```

Для macOS замените `python` на `python3` и COM3 на `/dev/cu.usbserial-...`. Можно использовать Python из `.venv`. Без `--port` автоматический выбор возможен при ровно одном найденном CP210x. `ports` печатает все порты. CLI по умолчанию закрывает порт, **оставляя USB-режим** для следующей команды (до 60 с простоя); `disconnect` или глобальный флаг `--exit-usb` отправляет BYE и возвращает обычный режим. Не запускайте CLI одновременно с GUI.

При неизвестном состоянии доставки после тайм-аута или сбросе сеанс закрывается: подключитесь заново и повторите файл целиком. Возобновления с произвольного смещения нет; так не смешиваются куски разных версий файла.

## Проверки

Из корня исходников: `./tools/test.sh`, затем `python3 test/usb_test.py` после установки Pillow/pyserial. Тест запускает **тот же C++ протокольный движок**, что включён в прошивку; host-файловый адаптер не является ESP32 LittleFS. Тестирует ошибки CRC/ACK, повторы, обрыв, сброс, отмену, защиту путей, форматы, 3 МиБ, массовое удаление и повторные сеансы. Отчёт `VERIFICATION-0.4.1.md`, спецификация `INHFS-1.md` включены в ZIP.
