# inhOS 0.1.1-alpha

Новая реализация ридера и платформы приложений для Heltec Wireless Paper / ESP32-S3, одна кнопка, экран 250×122.

**Статус:** разработка. Аппаратных испытаний нет. Это не подтверждённая замена оригинальной прошивки и не строгая разработка методом чистой комнаты: автор реализации ранее изучал её бинарный код. Оригинальные код, картинки и шрифты в проект не включены. Используются открытые драйверы и шрифты с сохранением лицензий.

## Две сборки

- `reader_v12`: ридер TXT/FB2, сохранение позиции и полный дисковый индекс страниц, загрузка по Wi-Fi.
- `apps_v12`: тот же ридер, главное меню и интерпретируемые приложения `.inh`.
- `reader_v11`, `apps_v11`: варианты для старого дисплея V1.1.

V1.1.1 и V1.2 используют E0213A367; V1.1 использует LCMEN2R13EFC1. Выбирать по маркировке панели, не по названию товара. Версия V1.0 пока не поддержана.

## Управление

В меню: один клик — следующий пункт; двойной — открыть; тройной — назад; удержание 1,3 с — главное меню (в reader-сборке — загрузка). В ридере: один — следующая страница, тройной — предыдущая, двойной — меню. В приложении удержание завершает его и освобождает память. Удерживаемая при пробуждении кнопка игнорируется до отпускания.

Через 120 секунд бездействия вне приложения/загрузки/индексации — заставка inhOS и глубокий сон. Позиция сохраняется в NVS, границы всех страниц — в LittleFS. Разметка не вызывает обновление дисплея. SPI и обновление экрана выполняет отдельная задача; новые кадры объединяются.

## Загрузка

Открыть «Загрузить», подключиться к `inhOS`, пароль `inhreader`, открыть `http://192.168.4.1`. Одна текущая книга до 3 МиБ, `.inh` до 32 КиБ. FB2 превращается в текст в браузере; изображения, оформление и сноски FB2 не сохраняются. Доступен выбор UTF-8 / Windows-1251 / UTF-16LE. Приложения загружаются тем же интерфейсом.

**Известные отличия от оригинала:** прежний `.knigo` не поддерживается; батарейный индикатор, часы, смена шрифта, Wi-Fi STA и удаление приложений через меню пока не реализованы. В настройках доступны разворот экрана и сброс позиции книги. Язык не совместим со всем Python. Поэтому полное повторение оригинальной функциональности не заявляется.

## Сборка

Python 3, PlatformIO Core 6.2.0:

```
python3 -m pip install platformio==6.2.0
pio run -e reader_v12 -e apps_v12
```

Зависимости закреплены в `platformio.ini`. Артефакты: `.pio/build/<вариант>/firmware.bin` и `firmware.elf`.

**Новая таблица разделов несовместима со старой. Нельзя записывать только firmware.bin поверх оригинальной прошивки с её таблицей разделов.** Для первой установки нужны bootloader (0x0), partitions (0x8000), firmware (0x10000), затем создание нового хранилища с подтверждением на устройстве. Это удалит старые книги. Сначала сохранить полный резервный дамп. Не переносить старую таблицу разделов в новую сборку. Для отката использовать исходный полный дамп по 0x0.

При ошибке монтирования файловой системы показывается предупреждение и требуется двойной клик для форматирования. Автоматического форматирования нет.

## Проверки

```
./tools/test.sh
# Для сред без поддержки ASan/LSan:
SANITIZERS=undefined ./tools/test.sh
```

Тестируется настоящий общий C++ код разметки, языка и кнопки. Проверки не эмулируют ESP32, SPI, Wi-Fi и физический экран. Даже успешная компиляция не заменяет испытаний на плате. Образы выпускаются как alpha.

## Исправление загрузчика 0.1.1

В выборе файлов снят фильтр расширений, который мог скрывать INH/FB2 на телефонах. Тип определяется по расширению без учёта регистра; названия приложений приводятся к допустимому виду. Страница показывает установленную сборку (Apps или Reader); Reader явно объясняет отсутствие поддержки приложений. Исправлены переносы строк и чтение FB2 с XML-пространством имён. Добавлен /info и запрет кеширования страницы.

Для проверки приложений выбирайте `apps_v11` или `apps_v12` под свою панель. Установленная Reader не превращается в Apps от загрузки .inh.

После уже установленной inhOS с этой таблицей разделов обновляется только `firmware.bin` по адресу **0x10000**. Повторная первая установка по 0x0 не требуется. Это обновление сохраняет существующий формат хранилища.

Архив исправления: [inhOS-0.1.1-alpha.zip](downloads/inhOS-0.1.1-alpha.zip) (публикуется после успешных тестов и сборок). Проверка портала: `node test/portal_test.cjs`; сеть и XML DOM в тесте подставлены, физическая загрузка на устройство не проверена.

## Ориентация дисплея

В «Настройки → Разворот 180» двойной клик переключает ориентацию, одиночный выбирает пункт, тройной возвращает в меню. Значение сохраняется в NVS и восстанавливается после сна и перезапуска. При первом запуске 0.1.1 разворот включён по умолчанию для корпуса пользователя; отключается тем же пунктом. Ориентация применяется ко всему кадровому буферу, включая текст, графику приложений и заставку.
